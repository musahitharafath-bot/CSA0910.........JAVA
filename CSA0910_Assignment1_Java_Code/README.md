# CSA0910 Java Assignment 1 — Campus Smart-Parking System

This pack provides one Java example folder for each of the 12 tasks in the supplied assignment.

## Folder structure
- `Task01` — problem objects and candidate-class demonstration
- `Task02` — data types, jagged arrays, and fee conversion
- `Task03` — completed `ParkingFacility` TODO program
- `Task04` — constructors, constructor chaining, and ticket objects
- `Task05` — static ticket numbering and object life cycle example
- `Task06` — vehicle inheritance hierarchy and constructor trace
- `Task07` — overriding, equality, hash code, and `final`
- `Task08` — completed `FeeDemo` TODO program (expected output preserved)
- `Task09` — abstract class and interfaces
- `Task10` — packages/access-modifier demonstration (single-file runnable example)
- `Task11` — integrated parking system with tests
- `Task12` — extended design with e-bikes, delivery vans, and one-day visitor passes

## Requirements
- Java 17 or newer is recommended. Task 8 uses pattern matching for `instanceof`, as in the assignment.
- Open a task folder in a terminal and compile/run its Java file. Example:
  ```bash
  javac Task03/ParkingFacility.java
  java -cp Task03 ParkingFacility
  ```
- For a simple one-file task:
  ```bash
  javac Task01/Task01Demo.java
  java -cp Task01 Task01Demo
  ```
- Task 10 is a runnable illustration of access control in one source file. In a larger project, split the classes into the packages described in its comments.
- Keep your own output screenshots and add them to each task folder before submitting.
- Make at least one Git commit per task, as required by the assignment.
- Update the README with your name, register number, Java version, and your own test results.
- Treat this as a learning scaffold: run each program, inspect the output, and be ready to explain the code during your viva.
